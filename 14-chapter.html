English Translation

(1) An OS is software that manages and controls hardware and application software; it is also called "basic software."

(2) Software that runs between the OS and applications, providing common basic functions, is called middleware.

（3）特定とくていのspecific 目的もくてきでpurpose 使つかうused 文書作成ぶんしょさくせいソフトやdocument creation software 表計算ひょうけいさんソフトなどをspreadsheet software （アプリケーションソフトウェア）（4）＿＿＿＿＿＿＿＿＿＿＿＿application softwareという。

(3) Software used for specific purposes, such as document creation and spreadsheet software, is called application software.

OS

Software that manages and controls hardware and applications — also called "basic software."

middleware (No. 3)
Software that runs between the OS and applications, providing common basic functions.

仮想かそうメモリ
virtual memory
An OS memory-management function that uses storage as if it were memory when memory runs out.
✓ Learned
マルチタスク
multitasking
The OS's task-management function that lets multiple programs run at the same time.
✓ Learned
ルートディレクトリ／カレントディレクトリ
root / current directory (No. 6, 7)
Root = the topmost directory. Current = the directory currently serving as the base of operations.
✓ Learned
絶対ぜったいパス／相対そうたいパス
absolute / relative path (No. 8, 9)
Absolute = specified from the root directory. Relative = specified from the current directory.
✓ Learned
バックアップ3種
full / differential / incremental
Full saves everything (long backup, fast recovery). Differential saves changes since the last full. Incremental saves changes since the last backup (short backup, slow recovery).
✓ Learned
OSS
open source software (No. 17, 18)
Software whose source code is published and can be modified/redistributed under license conditions — but you must follow the license!
✓ Learned
OCR／バーコードリーダー
OCR / barcode reader (No. 24, 25)
OCR reads printed characters and converts them to character codes. A barcode reader optically reads product barcodes.
✓ Learned
デジタイザ
digitizer (No. 26)
A device for inputting position information of blueprints or illustrations with a pen.
✓ Learned
有機ELディスプレイ
organic EL display
Self-emitting display — low voltage, low power consumption, and easy to make thin.
✓ Learned
ドットインパクトプリンター
dot impact printer (No. 30)
A printer that strikes an ink ribbon with pins — used for carbon-copy forms because it presses through layers.
