Key Terms重要用語 — 重要用語じゅうようようごkey terms
Glossary of terms from this unit
擬似言語ぎじげんごpseudo-language pseudo-language (pseudo-code)
A human-readable way of writing algorithms, used instead of a real programming language.
宣言部せんげんぶdeclaration part declaration part (No. 1)
The part of a pseudo-language program where functions and variables are declared.
処理部しょりぶprocessing part processing part (No. 2)
The part of the program where the actual processing is written.
型名かためいtype name type name (No. 3)
The data type written before a variable declaration, e.g. 整数型 or 実数型. Format: 型名：変数名.
注釈ちゅうしゃく／コメントannotation / comment comment (No. 4)
An explanatory note that does not affect the program's behavior. Written between /* and */.
代入だいにゅうassignment assignment (No. 5)
Storing the result of the right-hand expression into the left-hand variable, using the ← operator: 変数名 ← 式.
選択構造せんたくこうぞうselection structure selection structure — if (No. 6)
Branching between processes by condition: if → elseif → else → endif.
真しんtrue true (No. 7)
When a condition expression holds. A while loop repeats as long as the condition is 真 (true).
forfor loop keyword for (No. 8)
A repetition structure that loops for a specified range or count, ending with endfor.
添字そえじsubscript subscript / index (No. 9)
The element number of an array. Python and C start at 0, but this textbook's pseudo-language starts at 1 — a key trace trap.
関数の宣言かんすうのせんげんfunction declaration function declaration (No. 10)
Defining a function's name, return type, and parameters — line 01 of calcMean.
変数の宣言へんすうのせんげんvariable declaration variable declaration (No. 11)
Preparing the variables used in the processing: sum, mean, and the counter i.
初期化しょきかinitialization initialization (No. 12)
Setting a variable's starting value — e.g. sum ← 0 before accumulating.
制御変数せいぎょへんすうcontrol variable control variable & condition (No. 13)
The counter (i) that drives the loop, and the condition controlling its range (1 to the element count).
累積るいせきaccumulation accumulation (No. 14)
Repeatedly adding elements to a running total: sum ← sum + dataArray[i].
平均値へいきんちaverage value average / mean (No. 15)
The total divided by the element count: mean ← sum ÷ (number of elements).
戻り値もどりちreturn value return value (No. 16)
The value a function sends back to its caller — return mean on line 10.
トレーストレースtrace trace / tracking (No. 17–21)
Following a program line by line, recording how each variable's value changes at each step.
