Key Terms — 重要用語

✓ Learned
合計ごうけい
total / sum (No. 1, 5)
Adding multiple values together. Computed by repeatedly adding each value x into a running total y (y ← y + x).
✓ Learned
足たし算ざん
addition (No. 5)
The operation of combining numbers; what the total algorithm performs.
✓ Learned
探索たんさく・検索けんさく
search / retrieval (No. 2, 11)
Finding data that matches given conditions. The two main methods are linear search and binary search.
✓ Learned
適合てきごうするデータ
matching data (No. 11)
Data that satisfies the given search conditions — what a search looks for.
✓ Learned
線形せんけい探索たんさく（リニアサーチ）
linear search (No. 12, 14)
A search method that checks data one by one, in order from the head (先頭) to the tail (末尾). Simple, but can be slow for large data.
✓ Learned
2分ぶん探索たんさく（バイナリサーチ）
binary search (No. 13, 18)
A search method that checks the middle value and narrows down (絞り込む) the range to the front or rear half each time. Fast, but requires sorted data.
✓ Learned
併合へいごう（マージ）
merge (No. 3, 22)
Combining multiple sets of sorted data into one new array (配列), keeping the original order intact.
✓ Learned
整列せいれつ（ソート）
sort (No. 4, 24)
Changing the order (並び順) of data, e.g., into ascending order. Also called 並べ替え or "sort."
✓ Learned
並ならび順じゅん
order / arrangement (No. 24)
The sequence in which data is arranged. Sorting changes this; merging preserves it.
✓ Learned
バブルソート
bubble sort (No. 25, 38)
A sorting method that compares adjacent values (隣接同士を比較) from head to tail and swaps them (入れ替える) when their order is reversed. The largest value "bubbles" to the end each pass.
✓ Learned
挿入そうにゅうソート
insertion sort (No. 26)
A sorting method that takes each value and inserts it into its correct position among the already-sorted values.
✓ Learned
マージソート
merge sort (No. 27)
A sorting method that splits the data into parts, sorts each part, and then merges them together.
✓ Learned
選択せんたくソート
selection sort (No. 28)
A sorting method that repeatedly selects the smallest remaining value and moves it to its final position.
✓ Learned
クイックソート
quick sort (No. 29)
A fast sorting method that picks a pivot value, splits the data around it, and sorts each part recursively.
✓ Learned
昇順しょうじゅん
ascending order
Arranging data from smallest to largest (1, 2, 3…). The opposite is descending order (降順).
✓ Learned
初期化しょきか
initialization (No. 6)
Setting a variable to its starting value (e.g., y ← 0) before a calculation begins.
✓ Learned
先頭せんとう・末尾まつび
head / tail (No. 14, 15)
The beginning and end of a data set. Linear search scans from the head to the tail.
✓ Learned
隣接りんせつ同士どうし
adjacent pairs
Two data items next to each other. Bubble sort compares these pairs and swaps them if out of order.
✓ Learned
交換こうかん
swap / exchange
Exchanging the positions of two values. In bubble sort, adjacent values are swapped when their order is reversed.
