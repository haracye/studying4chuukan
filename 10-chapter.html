Lists

A list is a data structure in which each element is composed of a "data part" and a "pointer part."

In a list, by following the pointers, the data can be linked together.

A pointer indicates where the next piece of data is located in memory.

リストlist のconnection particle (of) 特徴とくちょうcharacteristic / feature はtopic marker 、comma データdata のconnection particle (of) 追加ついかaddition ・and (listing) 挿入そうにゅうinsertion ・and (listing) 削除さくじょdeletion がsubject marker （簡単かんたん） （12） ＿＿＿＿ easy であるis (plain form) 点てんpoint / aspect ですis (polite) 。period

キュー（Queue）

Queues
キューqueue はtopic marker 、comma データdata をobject marker 順番じゅんばんorder / turn にin / by (manner) 格納かくのうstore しand (connective) 、comma 「先さきに入いれたデータから順番じゅんばんに取とり出だす」 （13） ＿＿＿＿＿＿ retrieve in order, starting with the data entered first 数据構造データこうぞうdata structure ですis (polite) 。period
English Translation

A queue is a data structure that stores data in order and retrieves it starting with the data that was entered first.

これthis をobject marker 「先入せんにゅうれ先出せんだしし（FIFO：First-In First-Out）方式ほうしき」 （14） ＿＿＿＿＿＿ First-In, First-Out method とquotation marker 呼よびますis called (polite) 。period
English Translation

This is called the "First-In, First-Out (FIFO)" method.

意味いみimage / analogy ：colon 買かいshopping のconnection particle (of) 登録レジcash register やor / and 、comma 店みせshop にat / to 並ならぶline up / queue up 行列ぎょうれつline / row (of people) とwith / same as 同おなじthe same ですis (polite) 。period 後あとからlater / afterward 来きたcame 人ひとperson はtopic marker 行列ぎょうれつline のconnection particle (of) 後うしろbehind / back にto / at 並ならびlines up 、comma 先頭せんとうfront / head のconnection particle (of) 人ひとperson からfrom 順番じゅんばんin order にby (manner) 店みせshop にto / into 入はいってenter (te-form) 行いきますgo (polite) 。period

Image: It works like a checkout line or a queue of people at a shop. People who arrive later join at the back, and people enter the shop in order from the front.
