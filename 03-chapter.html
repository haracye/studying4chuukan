Key Terms重要用語 — 重要用語じゅうようようごkey terms
Glossary of terms from this unit
集合しゅうごうset set
A collection (group) of things that all satisfy a certain fixed condition.
ベン図ベンずVenn diagram Venn diagram
A diagram that shows relationships between sets as pictures. Devised by the 19th-century British philosopher and logician John Venn.
積集合せきしゅうごうintersection intersection (No. 3–4)
The set that satisfies both of two conditions (A かつ B). Written A ∩ B.
和集合わしゅうごうunion union (No. 5–6)
The set that satisfies either of two conditions (A または B). Written A ∪ B.
否定ひていnegation negation / NOT (No. 7–8)
The set that does not satisfy a given condition. Also called "A 以外" or "A の補集合."
補集合ほしゅうごうcomplement complement (set)
Everything outside a given set — the same idea as 否定. Written Ā or Aᶜ.
部分集合ぶぶんしゅうごうsubset subset (No. 9–10)
A set that is entirely contained inside another set. A ⊂ B means "A is a subset of B."
かつかつAND and (logical AND)
A connective meaning both conditions must be true at the same time.
またはまたはOR or (logical OR)
A connective meaning at least one of the conditions is true.
条件じょうけんcondition condition
A requirement used to decide which elements belong to a set.
所持者しょじしゃholder holder (of a license)
A person who holds a qualification, e.g. an IT Passport holder.
網掛け部分あみかけぶぶんshaded region shaded region
The shaded part of a Venn diagram, showing the set being described.
満たすみたすto satisfy to satisfy
To meet a condition or requirement.
含まれるふくまれるto be contained to be contained
To be included inside a set or group.
表記するひょうきするto notate to notate
To write something using a symbol or notation.
記号きごうsymbol symbol
A mark such as ∩, ∪, or ⊂ used to express a mathematical idea.
考案こうあんto devise to devise
To think up and design a new method or idea.
頭文字かしらもじinitial letter initial letter
The first letter of a word, such as the c in Complement.
