Key Terms — 重要用語じゅうようようご
Glossary of terms from this unit
二進数にしんすう binary number (No.1)
A number expressed using only the digits 0 and 1, which correspond to electricity being OFF and ON.
ビットビット bit (No.2)
The smallest unit of information a computer handles. Equals one digit of a binary number and can express only 2 states: 0 and 1.
バイトバイト byte (No.5–6)
A unit formed by grouping 8 bits together. The most important formula: 1 byte = 8 bits (256 possible states, 2 to the 8th).
接頭辞せっとうじ prefix
A marker attached to a unit to indicate scale: kilo (K), mega (M), giga (G), tera (T), peta (P).
キロバイトキロバイト kilobyte / KB
1,000 bytes in the exam's decimal base; originally 1024 bytes in binary. Roughly the size of text data.
メガバイトメガバイト megabyte / MB
1,000,000 bytes (10 to the 6th); originally 1024 KB. Roughly a high-quality photo.
ギガバイトギガバイト gigabyte / GB
1,000,000,000 bytes (10 to the 9th); originally 1024 MB. Used for smartphone capacities and movies.
テラバイトテラバイト terabyte / TB
10 to the 12th bytes (1 trillion); originally 1024 GB. Used for PC SSDs and hard disks.
ペタバイトペタバイト petabyte / PB
10 to the 15th bytes; originally 1024 TB. Used for data center capacities and beyond.
