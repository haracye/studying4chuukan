Key Terms — 重要用語じゅうようようご
Glossary of terms from this unit
人工知能じんこうちのう（AI） artificial intelligence
Programs and systems that perform the various intellectual activities that humans carry out.
機械学習きかいがくしゅう（ML） machine learning (No. 1)
A fundamental technology of AI. The computer loads enormous amounts of data, learns from it, and makes predictions and judgments.
深層学習しんそうがくしゅう（DL） deep learning
A machine learning technique modeled on the structure of the human brain (neural networks).
記述型人工知能きじゅつがたじんこうちのう rule-based AI
Conventional AI that operates on rules and processing created in advance by humans. Its uses are limited.
教師あり学習きょうしありがくしゅう supervised learning (No. 2)
A method in which learning data and its labels (correct answers) are given. Keywords: classification and regression.
教師なし学習きょうしなしがくしゅう unsupervised learning (No. 5)
A method in which only learning data is given, with no correct answers. Keyword: clustering.
強化学習きょうかがくしゅう reinforcement learning (No. 7)
A method in which no correct answers are given, but evaluations (rewards) are, so the computer learns control methods through trial and error.
分類ぶんるい classification (No. 3, 9)
A supervised learning algorithm that sorts data into multiple classes, e.g. sorting images into categories.
回帰かいき regression (No. 4, 10)
A supervised learning algorithm that predicts the future values of continuous data.
クラスタリング clustering (No. 6, 11)
An unsupervised learning algorithm that groups data based on the similarity between data points.
試行錯誤しこうさくご trial and error (No. 8, 13)
Repeatedly trying and failing in order to find the optimal behavioral rule (control method). The keyword for reinforcement learning.
ラベルラベル label
The correct answer attached to a piece of learning data in supervised learning.
報酬ほうしゅう reward
The evaluation given to an action in reinforcement learning instead of a correct answer.
画像認識がぞうにんしき image recognition
An applied AI technology that identifies what is in an image. Built on machine learning and deep learning.
音声認識おんせいにんしき voice recognition
An applied AI technology that understands human speech. Built on machine learning and deep learning.
自然言語処理しぜんげんごしょり natural language processing
An applied AI technology that processes human language (text). Built on machine learning and deep learning.
