Key Terms重要用語 — 重要用語じゅうようようごkey terms
用語ようごterms 集しゅうcollection — Glossary of terms from this unit
アルゴリズムアルゴリズムalgorithm algorithm (No. 1–3)
The "procedure," "calculation method," or "processing procedure" for solving a specific problem — like a recipe for a computer.
手順書てじゅんしょwritten procedure written procedure
A document listing steps in order. An algorithm is the "instruction manual" that makes a computer do its work.
フローチャートフローチャートflowchart flowchart
A diagram that expresses an algorithm visually. Also called a 流れ図 (flow diagram).
流れ図ながれずflow diagram flow diagram (No. 5)
Another name for a flowchart: a visual representation of processing steps.
端子たんしterminator symbol terminator symbol (No. 6–7, 11–12)
The rounded (stadium-shaped) symbol marking the start and end of processing.
処理しょり（四角しかく）process symbol process symbol (No. 8)
The rectangle symbol showing a concrete process such as a calculation or an assignment.
流れ線ながれせんflow line flow line (No. 9)
The arrow showing the flow of processing. In principle: top to bottom, left to right.
判断はんだん（菱形ひしがた）decision symbol decision symbol (No. 10)
The diamond symbol for a decision based on a condition, with Yes/No branches.
ループ端子ループたんしloop terminal loop terminal (No. 11–12)
The hexagonal symbol pair marking the start and end of a loop, expressing repetition.
順次構造じゅんじこうぞうsequential structure sequential structure (No. 13, 16)
Instructions are executed one after another, in order.
選択構造せんたくこうぞう（分岐構造ぶんきこうぞう）selection / branch structure selection / branch structure (No. 14, 17)
The flow of execution changes depending on a condition.
繰り返し構造くりかえしこうぞうrepetition structure repetition structure (No. 15, 18)
The same processing is repeated according to a condition.
前判定繰り返しまえはんていくりかえしpre-test repetition pre-test repetition (No. 19)
The repeat check happens before processing, so the process may run 0 times.
後判定繰り返しあとはんていくりかえしpost-test repetition post-test repetition (No. 20–21)
The repeat check happens after processing, so the process always runs at least 1 time.
