Key Terms — 重要用語じゅうようようごimportant terms

カードをタップして「習得済み」にする ✓ · 0 / 0 learned · Reset
✓ Learned
MTBF
Mean Time Between Failures (No. 1)
平均故障間隔 — the average time from one failure to the next. Longer = less likely to fail. Formula: 総稼働時間 ÷ 故障回数.
✓ Learned
MTTR
Mean Time To Repair (No. 2)
平均修復時間 — the average time from failure to repair completion. Shorter = faster recovery. Formula: 総修復時間 ÷ 故障回数.
✓ Learned
稼働率かどうりつ
availability (No. 5)
How much of the total time is usable. Formula: MTBF ÷ (MTBF + MTTR). Higher = better.
✓ Learned
直列ちょくれつシステム
series system (No. 8)
If any one component fails, the whole system stops. All must be normal. Availability: R₁×R₂×R₃ (multiplication).
✓ Learned
並列へいれつシステム
parallel system (No. 11)
If any one component is normal, the system works. Availability: 1−(1−R₁)×(1−R₂) — one minus the probability that all fail.
✓ Learned
故障率こしょうりつ
failure rate
1 minus the availability (1−R). In parallel systems, the failure rates are multiplied together.
