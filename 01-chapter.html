Key Terms — 重要用語じゅうようようご
Glossary of terms from this unit
基数変換きすうへんかん radix / base conversion
Converting numbers between bases, e.g. between decimal, binary, and hexadecimal.
10進数じゅっしんすう decimal number (No. ①)
Base-10 notation using the ten symbols 0–9; the digit carries over after 9. Used in human daily life.
2進数にしんすう binary number (No. ②)
Base-2 notation expressing all numbers with only 0 and 1. The basic unit of the IT world.
16進数じゅうろくしんすう hexadecimal number
Base-16 notation. It appears in this chapter's title, but the provided material is cut off before its explanation.
電子回路でんしかいろ electronic circuit
The physical circuits inside a computer. They can directly understand only two signal states, ON/OFF.
電気信号でんきしんごう electric signal
The electrical on/off (high/low voltage) signals that electronic circuits work with.
電圧でんあつ voltage
Electrical pressure. Its "high" and "low" states are one way to represent the two states a circuit understands.
桁けた digit place
A position in a number. In decimal it carries over after 9; in binary after 1.
重みおもみ weight
The value each binary digit carries: from the right, 2⁰(=1), 2¹(=2), 2²(=4), 2³(=8), and so on.
ビットビット bit
One digit of a binary number — one ON/OFF state. In binary, each 桁 is one bit.
バイトバイト byte (No. ③)
8 bits grouped together. In IT systems, 8 bits = 1 byte.
数値表現すうちひょうげん number representation
The way numbers are written, such as decimal in daily life or binary in computers.
記号きごう symbol / digit
A written character representing a value, e.g. the ten symbols 0 through 9 in decimal.
基本単位きほんたんい basic unit
The fundamental unit something is built on — binary serves as the basic unit of the IT world.
