Key Terms — 重要用語じゅうようようご
Glossary of terms from this unit
補助単位ほじょたんい auxiliary unit
A unit smaller than 1, used to express extremely short processing times or microscopic data.
ミリミリ（m） milli
One thousandth. 10⁻³ = 0.001 = 1000分の一.
マイクロマイクロ（μ） micro
One millionth. 10⁻⁶ = 0.000001 = 100万分の一. The Greek letter μ is the symbol.
ナノナノ（n） nano
One billionth. 10⁻⁹ = 0.000000001 = 10億分の一.
ピコピコ（p） pico
One trillionth. 10⁻¹² = 0.000000000001 = 1兆分の一.
累乗るいじょう power (of a number)
Repeated multiplication of a number by itself, e.g. 10⁻³. A negative power expresses a fraction (1/1000, etc.).
文字コードもじコード character code (No. 4-2)
A correspondence table that links each character with binary numbers so computers can display text.
対応表たいおうひょう correspondence table (No. 4-1)
A lookup table pairing characters with 2進数 (binary numbers) — this is what a 文字コード is.
アスキーコードアスキーコード ASCII code (No. ①)
US standard character code centered on half-width alphanumeric characters; the foundation of Japanese and world standards.
シフトJISシフトジス Shift.JIS (No. ②)
A code that extended ASCII to handle Japanese characters such as hiragana and kanji.
ユニコードユニコード Unicode (No. ③)
A worldwide common character code that handles diverse scripts within one unified system.
UTF-8 UTF-8
An encoding format of Unicode data, designed for efficient computer handling; the most widespread format on the Web.
半角英数字はんかくえいすうじ half-width alphanumeric characters
Narrow (half-width) letters and digits such as "A" and "1" — the core characters handled by ASCII.
2進数にしんすう binary number
A number expressed using only 0 and 1 — the only "language" a computer understands.
符号化ふごうか encoding
Converting data into a coded form (such as UTF-8) that a computer can handle efficiently.
